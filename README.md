# 🌦️ 대기 안정도와 강수 — 교육용 시뮬레이션 웹앱

고등학교 지구시스템과학 **"대기 안정도와 강수"** 단원(단열 변화 · 푄 현상 · 대기 안정도)을 위한
시뮬레이션 중심 + 게임 요소(미션/별) 수업 도구입니다.
수업 중 교사 주도 활동용으로, 프로젝터/전자칠판에 크게 띄워 사용하도록 설계했습니다.

## 실행 방법

빌드가 필요 없습니다. **`index.html`을 브라우저(Chrome/Edge 권장)로 열면 바로 실행**됩니다.
외부 서버·DB·인터넷 연결이 전혀 필요 없으며, 진행 상황(별)은 페이지를 새로고침하면 초기화됩니다.
헤더 오른쪽 🔄 버튼으로도 별을 초기화할 수 있습니다 (새 수업 시작용).

## 구성

| 탭 | 내용 | 미션 |
|---|---|---|
| 🎈 상승 실험실 | 공기 덩어리(풍선)를 올리며 건조/습윤 단열 변화와 상승 응결 고도 관찰 | 구름 만들기 / 구름 바닥 2.0 km 맞추기 / 4 km에서 5 ℃ 만들기 |
| ⛰️ 산 넘기 | 푄 현상(높새바람) 재현 — 동쪽(영동)에서 서쪽(영서)으로 산을 넘는 공기 | 높새바람 만들기 / 도착 온도 예측 / 온도 차 최대화 |
| ⚖️ 안정도 실험실 | 환경 기온 감률 γ 조절, 쿡 찔러보기·강제 상승으로 안정도 탐구 | 층운형 / 적운형 / 조건부 불안정에서 적운 발달 |

별 9개를 모두 모으면 **기상 마스터 수료증**이 표시됩니다.

## 물리 규칙 (교과서 값)

- 건조 단열 감률 **10 ℃/km**, 습윤 단열 감률 **5 ℃/km**, 이슬점 감률 **2 ℃/km**
- 상승 응결 고도 **H(km) = ⅛ × (T − Td)**
- 안정도: γ < 5 절대 안정 / γ > 10 절대 불안정 / 5 < γ < 10 조건부 불안정
- 안정 대기 강제 상승 → 층운형, 불안정 대기 → 적운형

물리 계산은 전부 `physics.js` 한 파일에 있습니다.

## 미션 난이도 조정 (교사용)

`app.js` 맨 위의 `TUNING` 상수에 각 미션의 목표 수치와 판정 허용 오차가 모여 있습니다.
예: 탭 1 미션 3의 온도 허용 오차를 늘리려면 `m3_tolTemp: 0.25`를 `0.5`로 바꾸면 됩니다.

## 테스트

```bash
node test.js
```

교과서 검증 케이스를 포함한 물리 엔진 테스트 35개가 실행됩니다.

- T=20 ℃, Td=12 ℃ → H=1.0 km, 1 km에서 10 ℃, 3 km에서 0 ℃
- 출발 20 ℃/이슬점 14 ℃/산 2 km → H=0.75 km, 정상 6.25 ℃, 도착 26.25 ℃
- γ=8, 지표 30 ℃/22 ℃ → 0.5 km에서 25 ℃ vs 26 ℃(복귀), 2 km에서 15 ℃ vs 14 ℃(자유 상승)
