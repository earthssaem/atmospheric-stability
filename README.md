# 🌦️ 대기 안정도와 강수 — 시뮬레이션 실험실

고등학교 지구시스템과학 **Ⅲ-03 「대기 안정도와 강수」**(교과서 92~99쪽, 5~9차시) 수업용 웹앱입니다.
교과서 순서대로 단열 변화 → 푄 → 대기 안정도 → 단열선도 탐구 → 안개 → 강수 과정을 시뮬레이션으로 탐구하고,
실험실마다 미션 3개(별 18개)에 도전할 수 있습니다. 프로젝터·전자칠판·태블릿·휴대폰 화면 모두에 맞춰집니다.

## 실행 방법

빌드가 필요 없습니다. **`index.html`을 브라우저(Chrome/Edge 권장)로 열면 바로 실행**됩니다.
외부 서버·데이터베이스·인터넷 연결이 필요 없고, 학생 정보를 저장하거나 보내지 않습니다.
모은 별은 새로고침하면 초기화되며, 오른쪽 위 ↺ 버튼으로도 초기화할 수 있습니다(새 수업 시작용).
맨 위 제목을 누르면 처음 화면(1. 단열 변화)으로 돌아갑니다. 다른 실험실의 설정과 별은 그대로 남습니다.

실험실마다 **개념 정리**와 **생각해 보기**(교과서 확인 문제·스스로 확인하기, 예시 답안은 눌러야 보임)가 있습니다.
별 18개를 모두 모으면 **기상 마스터 수료증**이 표시됩니다.

## 물리 규칙 (교과서 값)

- 건조 단열 감률 **10 ℃/km**, 습윤 단열 감률 **5 ℃/km**, 이슬점 감률 **2 ℃/km**(불포화) · 포화 시 이슬점도 5 ℃/km
- 상승 응결 고도 **H(km) = ⅛ × (T − Td)**
- 안정도: γ < 5 절대 안정 / γ > 10 절대 불안정 / 5 < γ < 10 조건부 불안정, γ < 0은 역전층
- 상대 습도 = 현재 수증기압 / 포화 수증기압 × 100 (Magnus 식으로 계산)
- 빙정설 그래프: 물과 얼음에 대한 포화 수증기압(Magnus 식) — 차이는 약 −12 ℃에서 최대(약 0.27 hPa)
- 안개(복사·이류)와 병합설 모형은 개념을 보여 주기 위한 **단순 모형**입니다(크기·속도 과장).

교과서 그림과 같은 색을 씁니다: **건조 단열 = 주황, 습윤 단열 = 파랑, 기온 변화선(주위) = 초록, 이슬점 = 보라**.

## 미션 난이도 조정 (교사용)

`js/config.js`의 `TUNING`에 미션 목표 수치와 허용 오차가 모여 있습니다.
예: 1번 미션 3의 기온 허용 오차를 늘리려면 `m3_tolTemp: 0.25`를 `0.5`로 바꾸면 됩니다.

## 테스트

```bash
node test.js
```

교과서 검증 케이스를 포함한 물리 엔진 테스트 62개가 실행됩니다.

- T=20 ℃, Td=12 ℃ → H=1.0 km, 1 km에서 10 ℃, 3 km에서 0 ℃
- 출발 20 ℃ / 이슬점 14 ℃ / 산 2 km → H=0.75 km, 정상 6.25 ℃, 도착 26.25 ℃
- 그림 Ⅲ-15~17: 지표 30 ℃, H=2 km, γ=8일 때 안정/불안정 경계 3.33 km
- 탐구: (가) 0~300 m −10 ℃/km(역전층·절대 안정), 300~500 m 14 ℃/km(절대 불안정), (나) 6 ℃/km(조건부 불안정)
